# @shikho/ui

React component library for the Shikho Design System, built with Tailwind CSS v4, `tailwind-variants`, and `clsx`.

**Status:** foundation scaffold only — contains a single placeholder component proving the `tokens -> icons -> ui` build chain. Real components land per `docs/npm-design-system-implementation-plan.md` §6.2 (build tier order), starting with `Button`.
